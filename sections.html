3
SCHULEN IN DER NÄHE / School Finder
Overline: "SCHULEN IN DER NÄHE". Headline: "Schulen in der Nähe." PLZ input + Radius dropdown (10/20/30/50/100 km, default 30 km) + search button. On submit: geocodes PLZ via Nominatim, then queries Overpass API for schools within radius. Results split into Partnerschulen (~33%) and Netzwerkschulen (~67%). Stat tiles show both counts. Tab bar to switch between both lists. Table columns: Schulname, Ort, PLZ, Entfernung (sorted ascending). Auto-expands radius up to 3× if fewer than 5 results found, shows a discreet hint line below the headline.
interactive PLZ search live API tabs radius fallback
HTML id: id="schulen-suche" · Input: id="plz-input" · Dropdown: id="radius-select" · Button: id="schulen-search-btn"
Results: id="schulen-results" · Counts: id="partner-count" / id="network-count" · Table body: id="schulen-table-body"
APIs: Nominatim (geocoding) · Overpass FR mirror (school data) · Haversine distance calc
